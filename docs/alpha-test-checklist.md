# Closed Alpha Checklist

Invite 50–200 players after the core loop is playable on Firebase (not emulators).

## Gate

Set `config/liveOps.featureFlags.alphaGate` to `true` and add tester emails to `config/allowlist.emails`.

## Test

- [ ] Account create / sign in
- [ ] Viking creation
- [ ] Daily login
- [ ] Energy/stamina regen after waiting
- [ ] Quests in chapter 1–2
- [ ] PvE combat and loot
- [ ] Equip item
- [ ] Recruit a warrior
- [ ] Collect village resources
- [ ] Upgrade a building
- [ ] Device compatibility (iOS + Android)
- [ ] Tutorial/onboarding clarity
- [ ] Session length and “is this fun?”

Do not optimize monetization during alpha. File bugs by severity: crash, progress-block, economy, UX.
