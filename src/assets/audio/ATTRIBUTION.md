# Audio attribution

All battle audio in this folder is original synthesized game audio created for Vikings War.

| File | Use |
| --- | --- |
| `battle_theme.wav` | Looping Nordic war-march battle music (drums + horns) |
| `sfx_attack.wav` | Sword / axe swing |
| `sfx_special.wav` | Heavy special strike |
| `sfx_defend.wav` | Shield clang |
| `sfx_potion.wav` | Potion drink / restore |
| `sfx_hit.wav` | Impact when a strike lands |

License: original work for this project. No third-party samples.
