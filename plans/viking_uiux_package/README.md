# Viking Game UI/UX Package

This package contains:

- `Viking_Game_UI_UX_Complete_Plan.md` — complete UI/UX roadmap
- `asset_manifest.md` — complete recommended UI/UX asset inventory
- `assets/` — production-ready folder structure for organizing future artwork, icons, characters, buildings, animations, audio, and store assets

The asset directories are placeholders; actual artwork can be produced during the UI/UX art phase.
