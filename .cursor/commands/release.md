# Prepare Release

Prepare the React Native project for production release.

Verify:

## General

- TypeScript
- ESLint
- Tests
- Environment configuration
- Production API configuration
- Analytics
- Crash reporting
- Feature flags

## iOS

- Bundle identifier
- Version
- Build number
- Signing
- Provisioning
- Entitlements
- Permissions
- Privacy configuration
- Release build

## Android

- Application ID
- Version code
- Version name
- Signing
- Permissions
- Target SDK
- Release build
- R8/ProGuard configuration

Do not change version numbers or signing configuration unless explicitly requested.

Do not claim the release is ready until the relevant release build has been verified.
