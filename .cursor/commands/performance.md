# Optimize React Native Performance

Analyze the selected code for actual performance problems.

Investigate:

- Excessive renders
- Large lists
- Expensive calculations
- Unnecessary effects
- Unstable props
- Context updates
- Image memory usage
- Animation performance
- JS thread workload
- Native/JS communication

Do not add useMemo, useCallback, or React.memo automatically.

First determine the actual cause of the performance problem.

Prefer measurable improvements.

After optimization, explain:

- Identified bottleneck
- Root cause
- Changes made
- Expected improvement
- How the change was verified
