# Create React Native Component

Create a production-ready React Native component following the project's existing design system.

Before implementation:

1. Inspect existing components.
2. Reuse existing UI primitives.
3. Follow existing styling conventions.
4. Follow TypeScript conventions.

The component should:

- Have a single responsibility.
- Use explicit TypeScript props.
- Support accessibility.
- Avoid unnecessary state.
- Avoid unnecessary effects.
- Avoid premature memoization.
- Handle relevant loading/error/empty states.

Add tests for important behavior.

Do not introduce a new design-system abstraction if an existing component can be reused.
