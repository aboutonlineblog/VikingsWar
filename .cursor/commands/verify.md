# Verify Changes

Verify the current implementation before considering the task complete.

Run the appropriate:

- TypeScript checks
- ESLint
- Unit tests
- Component tests
- Integration tests
- E2E tests
- iOS build checks
- Android build checks

Inspect:

- Git diff
- Unused imports
- Dead code
- Debug logging
- TODOs introduced by the change
- Unrelated modifications
- Error handling
- Loading states
- Empty states
- Accessibility

Do not claim a check passed unless it was actually executed.

Report:

- Checks executed
- Checks passed
- Checks failed
- Remaining warnings
- Remaining risks
